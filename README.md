# AGS 数据台 · 使用说明

给你的好氧颗粒污泥 AOA 系统做数据管理的本地小工具。数据存在你自己的电脑里，不联网、不登录、关掉也不会丢。

## 前置条件

需要先装 **Node.js**（自带 npm）。如果还没装：

1. 打开 https://nodejs.org/
2. 下载左侧的 **LTS** 版本（推荐，绿色按钮）
3. 双击安装包一路"下一步"，所有选项保持默认
4. 安装完成后 **重启电脑**（让 PATH 生效）
5. 重新双击 `start.bat`

> 怎么验证装好了？按 `Win+R` 输入 `cmd`，回车后输入 `node -v` 和 `npm -v`，能看到版本号（比如 v22.11.0）就成功了。

## 怎么打开

**电脑上：双击 `start.bat`**，稍等十几秒（第一次会装依赖、构建，之后每次只要几秒），浏览器会自动打开。

> 如果浏览器没自动打开，手动访问 `http://localhost:4173`。
> 如果弹出"找不到 npm"或"Node.js not installed"，回到上一节装 Node.js。

## 第一次使用（三步）

1. **系统设置 → 反应器**：确认或修改你的罐（R1、R2、R3…）
2. **系统设置 → 标准曲线**：给氨氮、硝态氮、亚硝态氮、总P 各建一条标曲——把标液的浓度和吸光度填进去，它会自动算出 k、b、R² 并画出拟合直线
3. **数据录入**：选日期 → 填进水 → 逐罐填吸光度，浓度自动出来 → 点保存

> COD 是仪器直读的，不用建标曲，录入时直接填浓度。

## 六个模块

| 模块 | 干什么 |
|---|---|
| 数据录入 | 每天测的氨氮/硝氮/亚硝氮/总P/COD，填吸光度自动出浓度 |
| 全周期 | 每隔几小时的密集采样，能从 Excel 整块粘贴进来，自动算峰值/最低/降到目标值用时 |
| 查询整理 | 按日期、罐、指标筛选，改数、删数、导出 Excel |
| 可视化 | 日常趋势图、周期曲线、周期叠周期，可导出图片 |
| 统计分析 | 去除率、亚硝积累率 NAR、均值±标准差、达标率、相关性 |
| 系统设置 | 反应器、标准曲线、自定义指标、备份与导出 |

## 几个关键点

- **重做标曲不会改老数据**：新建标曲只对生效日之后的数据生效，以前算出来的浓度一个数字都不会变。
- **稀释倍数可以单独改**：默认用指标设置里的倍数，某一次不一样就在那一格改，只影响那一格（橙色标记）。
- **没测的格子留空**，显示"—"，不会被当成 0。

## 手机端

手机和电脑连**同一个 WiFi**，然后：

1. 双击 `start.bat`（已经自动配好 HTTPS 自签证书）
2. 看黑框里打印的 **Phone access** 地址（形如 `https://192.168.x.x:4173`，用 IP 开头那个）
3. 手机浏览器打开这个地址
4. **第一次会提示"不是私密连接 / 不安全"**——这是自签证书的正常现象，点「高级 → 继续访问」信任一次即可（之后不会再提示）
5. 打开后就能正常使用了

### 装成"app"图标（添加到主屏幕、离线也能开）

- **Android（Chrome）**：菜单（右上角 ⋮）→ 「添加到主屏幕」→ 确认
- **iPhone（Safari）**：分享按钮（□↑）→ 「添加到主屏幕」→ 添加

添加后桌面会出现图标，打开是独立的全屏窗口，**断网也能打开**（数据缓存在手机本地）。

> 注意：
> - 电脑的 `start.bat` 黑框必须一直开着，手机才能访问（关了服务器就断了）
> - 手机上的数据是**独立存的一份**，用「系统设置 → 备份与导出」里的**导出备份文件 / 导入备份文件**在手机和电脑之间搬运
> - 证书有效期 1 年；如果电脑 IP 变了（换 WiFi / 重启路由器），启动时会自动重新生成证书，手机**重新信任一次**即可

## 备份（重要）

数据存在浏览器本地，**清浏览器缓存会清掉数据**。请定期用「系统设置 → 备份与导出 → 导出备份文件」存一份到别处。

## 常见问题

- **浓度显示"—"**：这个指标还没建标曲，或当天没有生效的标曲，去系统设置里建。
- **数字标黄**：负值、低于检出限、或超出参考范围，软件只提醒、不替你改。
- **想加指标**（氯离子、EPS、粒径、MLSS 等）：系统设置 → 自定义指标 → 新增。

## 技术说明

纯前端应用，React + TypeScript + Vite，数据存在浏览器 IndexedDB。没有后端、没有数据库软件。
