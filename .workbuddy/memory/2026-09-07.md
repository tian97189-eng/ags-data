
## 污泥浓度改「反应器 × 3滤纸平行样取均值」（09-07 用户要求，commit 42825ec）
**需求**：一个反应器测 MLSS 需 3 张滤纸（平行样），测出 3 个值取均值。多反应器则每组 3 张。
**方案（用户拍板）**：3纸分组卡片 + 均值与 3 明细同显。
**实现**（MLSSPage 全面重写，schema MLSSRecord 加可选 slot 字段）：
- 顶部：日期 + 反应器 chips（复用 db.reactors，默认第一个）；自动 3 张滤纸卡（R1-1/2/3 = code-slot）
- 每张卡输入即自动保存：按 (date+reactorId+slot) upsert，**模块级串行写队列 writeChain 防连续输入竞态**（否则连续 change 快速 fire 会 add 两行）
- 每张卡显示「已填 N/5」+ 本张 MLSS；可分天补全
- 底部均值卡：三滤纸均值 MLSS/MLVSS + 3 明细（用户选"均值+3明细都要"）
- 历史记录按反应器分组（组头均值 + 桌面表格 + 手机卡片）；旧记录（reactorId null/无 slot）兼容显示「旧」组
**测试重写关键经验**：
1. fireEvent 连续多字段 change 会因 dexie 异步 + React batch 竞态 → 逐字段 type() + waitRowCount flush
2. number input 渲染归一化（0.1000→0.1），不要断言 input.value 字符串
3. fake-idb clear 不重置自增 → reactorId 断言不能用固定 id（用 find slot/paperNo）
4. 旧记录无 reactorCode → 组头不显示均值（legacy 组只显示自身行）
**结果**：+6 新测试（494 全过），build 成功；用户需重打 APK
