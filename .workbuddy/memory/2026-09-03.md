
## 定位权限手机端用不了（08:22 用户反馈，commit dee39a6）
根因链：
1. **Manifest 已声明 ACCESS_COARSE/FINE_LOCATION**（issue 7 已加）
2. **@capacitor/geolocation 8.2.2 装了**，但**没 cap sync** → Android 工程的 settings.gradle / capacitor.build.gradle 根本没引 geolocation 插件 → APK 里没 Java 实现
3. **MainActivity 是空 `{}`**，没自定义权限申请
4. Android 设计：APK 里**未实际申请过**的位置权限，**系统设置 → 应用权限里不显示"位置"分类**（用户截图正如此）

修复：
1. **绕过 safe-delete 跑 cap sync android**：删 cordova_plugins.js 残留 + cordova-android-plugins 旧目录 → sync 成功（settings.gradle apply capacitor.settings.gradle + capacitor.build.gradle implementation project(':capacitor-geolocation')）
2. lib/geolocation.ts 新增 **requestLocationPermission()** helper（只申请不取位置，web 静默返 false）
3. **Overview mount 时主动调用 requestLocationPermission**——用户首次进概览页就弹原生权限框，接受后系统设置里"位置"分类立刻出现

测试 +5（lib helper 4 + Overview mount 1）→ 478 全过

**用户必做**：重打 APK（build-apk.bat）才能拿到新 link 的 Geolocation 插件 Java 实现；第一次打开 APK 概览页会立即弹位置权限对话框，允许 → 设置里"位置"出现 + 天气自动定位可用。
